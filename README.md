# Paradise Nursery Shopping Application

Paradise Nursery is a plant shop storefront built with React and Redux Toolkit.

## Features

- Landing page with a branded hero section and a Get Started button
- Product listing grouped into categories with six houseplants per category
- Add-to-cart behavior with dynamic cart count
- Shopping cart page with quantity controls, delete actions, totals, and checkout messaging
